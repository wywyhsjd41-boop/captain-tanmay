⚙️ Save & settings

Install on Android

When this app is hosted on a secure website (HTTPS), open it in Chrome → tap ⋮ → Add to Home screen / Install app. Then launch it from its home-screen icon.

This is an installable web app (PWA), not a Play Store APK. Offline app shell is supported after the first online visit.

Backup your journey

Export all logs, chapters, plans, coins, dates and workout records to a JSON backup file.

Notifications require browser permission and may not fire reliably when the app is closed or the phone is locked. Use Android Clock for critical alarms.

Data control

Your data stays in this browser on this device. Clearing browser storage can erase it, so export backups regularly.
