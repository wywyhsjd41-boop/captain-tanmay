UPDATE AN EXISTING GITHUB PAGES APP
1. In the currently installed app, open More → Export backup before updating. This is a safety copy.
2. Extract this ZIP. The ZIP contains the app files at its top level: index.html, manifest.json, sw.js, icon-192.png and icon-512.png.
3. Open your existing GitHub repository → Add file → Upload files.
4. Upload these extracted files to the repository root (the same level as the existing index.html), replacing files with the same names. Do not upload the ZIP itself and do not put the files inside an extra folder.
5. Commit changes. Keep the repository name and GitHub Pages URL unchanged.
6. Wait for the GitHub Pages deployment to finish. Open the same app URL in Chrome, reload it, then close and reopen the installed home-screen app. The service worker should install the v4 cache and remove the previous app-shell cache.

DATA SAFETY
- Updating files at the same GitHub Pages URL keeps the same browser origin, so the existing app's localStorage study data and IndexedDB workout videos should remain in place. Still export a JSON backup first.
- Do not clear Chrome/site storage or uninstall the app during the update.
- Uploaded workout videos are stored separately in IndexedDB and are not included in the JSON backup. Keep the same site URL/origin to retain them.
- If data is missing after update, use More → Import backup. Video files cannot be restored from the JSON backup.

This is an installable Progressive Web App (PWA), not a native APK or Play Store app. Original anime-inspired vector environments are used; they are not official character artwork or 3D game animations.
